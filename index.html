Getting Started

How to use:

  1. Paste your YAML configuration or upload a file
  2. Click "Validate" to check syntax and deprecated patterns
  3. Review issues in the right panel
  4. Click "Auto-Fix" for automatic corrections
  5. Review and copy the corrected output

Issue Types:

  • ❌ Errors: Critical syntax issues that break your config
  • ⚠️ Warnings: Non-critical issues that might cause problems
  • 🔄 Deprecated: Old syntax that still works but should be updated

Features:

  • ✓ Validates YAML syntax
  • ✓ Detects deprecated Home Assistant patterns
  • ✓ Auto-fixes common issues
  • ✓ Dynamically syncs with HA documentation
  • ✓ Multiple sources: GitHub releases, breaking changes, core deprecations

⚠️ Always test your configuration in Home Assistant before deploying changes.
